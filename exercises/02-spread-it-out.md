# Exercise 2: Spread It Out

**Time:** 10 minutes  
**After:** Strategy section (evolution, climate)

Add the evolution axis to your map.

## Evolution Stages

### Genesis (Far Left)
Brand new, rare, expensive, uncertain
- Example: Quantum computing (2020)

### Custom-Built
Bespoke for your context
- Example: Your domain model, code review process

### Product (+Rental)
Available to buy, competing products
- Example: CI/CD tools, test frameworks

### Commodity (+Utility)
Standardised, pay-per-use
- Example: Cloud compute, Git, email

## Your Task

1. **Mark obvious commodities** (far right): Cloud, Git, AI agent
2. **Mark what's uniquely yours** (left): Domain knowledge, architecture decisions
3. **Fill the middle**: CI/CD, test frameworks
4. **Debate!** Disagreement = interesting conversation

## Evolution Rules

**Key insight:** Evolution is about the **market**, not your maturity.

| Component | Evolution |
|-----------|-----------|
| Your code | Custom-Built |
| AI coding agent | Commodity (you bought it) |
| Domain knowledge | Genesis/Custom-Built |
| Test frameworks | Product |
| Cloud platform | Commodity |

## Discussion

1. Which placement surprised you?
2. What became commodity recently?
3. Where did you disagree most?
