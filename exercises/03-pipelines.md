# Exercise 3: Three Pipelines

**Time:** 15 minutes  
**After:** Pipelines section

A **pipeline** shows multiple ways of doing the same thing at different evolution stages.

## Your Task

Draw three pipelines showing how practices evolve:

### Pipeline 1: Writing Specifications
- Genesis/Custom: Prototype-driven, event storming
- Product: User story templates, BDD scenarios
- Commodity: Standard API contracts (OpenAPI)

### Pipeline 2: Writing Code
- Genesis/Custom: Hand-written, pair programming
- Product: AI-assisted coding (Copilot)
- Commodity: AI agents writing full features

### Pipeline 3: Quality Control
- Genesis/Custom: Manual testing, senior code review
- Product: Automated testing, AI code review
- Commodity: Continuous testing platforms

**Mark where YOU are today** with a dot. Draw arrows for intended moves.

## Pipeline Rules

1. New inventions start **left** (even if they feel advanced)
2. Industrialized old activities go **right** (however new)
3. Arrows: Dashed = market evolution, Solid = your push

## Questions

1. **Are pipelines out of step?**
   - Fast coding + slow review = bottleneck
   
2. **Where's the inertia?**
   - "Only seniors understand the domain"
   
3. **What must co-evolve?**
   - If coding moves right, quality must too

## Discussion

1. Where are pipelines mismatched?
2. Are AI evals Genesis or industrialized review? (Both!)
3. What resists moving right?
