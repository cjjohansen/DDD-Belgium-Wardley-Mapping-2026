# Erik Schön's annex: the curated collection of Wardley maps

The annex of *The Art of Strategy* is the largest public collection of Wardley maps: 168 maps by
about 90 mappers, updated 27 November 2025, CC BY-SA 4.0 (the text by Erik Schön, the mapping
courtesy of Simon Wardley). Read it at https://blog.stackademic.com/the-art-of-strategy-811c00a96fad
(also on Medium under the same title). Each entry there has the map image, a one-line description
and a reading time; this file is only the index, crawled 17 Oct 2026 so nobody has to read the
whole page to know what is in it. It is kept apart from the book table in `wardley-sources.md` on
purpose: ten books are readable, 168 maps are not.
